一、产品概览

桌面倒计时类工具并不少见，但它们普遍存在同一个问题：要么一直悬在最上层遮挡内容，要么需要在 App、浏览器标签之间来回切换。CountdownSideBar 的设计出发点很明确——把“还剩多少天”这件事做得存在感极低，却又能一眼看见。

它以一个圆角半透明小窗的形式停在屏幕边缘，常驻显示但不占任务栏；检测到前台全屏或最大化窗口时，小窗会自动让位。所有功能围绕“安静、清晰、可控”三点展开：

  • 安静：全屏自动让位、支持整窗点击穿透、临近 7 天才出现呼吸提示，平时绝不打扰。
  • 清晰：大号天数数字 + 实时时钟 + 进度条，数字字号可调到 72 px，教室后排也能看清。
  • 可控：位置、尺寸、透明度、配色、字体、标语全部可自定义，且每个目标独立记忆。

二、核心卖点

以下 12 项卖点逐条对应程序中的真实实现，可直接用于商品详情页与宣传物料。

  • 侧边停靠，永不挡事。无边框半透明玻璃质感小窗，可停在屏幕任意位置，置顶常显、不占任务栏；松手后在 26 像素内自动吸附到屏幕边缘，也可一键锁定位置防止误拖。
  • 多目标并行，一个目标一个窗口。高考、纪念日、项目上线可以同时存在，每个目标各自独立成窗、各自记忆位置与尺寸，互不干扰，还支持“全部显示 / 全部隐藏”。
  • 全屏自动让位。检测到前台全屏或最大化窗口时，小窗要么沉到窗口最底层（不缩小，且每秒压回底部，绝不遮挡视频），要么收缩成 196 × 76 的迷你条（双击可临时展开），两种策略独立开关、二选一。
  • 点击穿透，彻底不挡鼠标。开启后鼠标事件整窗穿透到下层窗口，看电影、打游戏时小窗看得见、摸不着，完全不影响操作。
  • 倒计时 + 正计时双模式。不只是“还有多少天”，正计时模式可记录“已经坚持了多少天”，适用于戒烟、健身、背单词、早睡等累积型打卡场景。
  • 20 套配色预设 + 四主色自定义。内置午夜蓝、松林绿、赛博、鎏金、樱花等 20 套整套配色，一键切换；也可自行挑选窗口背景、卡片背景、强调色、文字颜色，系统自动推导出全套界面配色，保证任意配色下都协调不脏。
  • 背景图片自定义。可将喜欢的图片设为小窗与主窗口背景，支持填充 / 适应 / 拉伸三种方式，并可调不透明度、0–12 级模糊与色调暗化，图片再花也保证数字清晰可读。
  • 标语节点，按天数自动切换文案。可自建“剩余 ≤ N 天”的节点（如 ≤100 天 / ≤30 天 / ≤7 天 / ≤1 天），进入区间自动切换寄语；旧版“每日寄语”文本可一键迁移为节点。
  • 临近 7 天呼吸提示。只在剩余 7 天以内启用边框呼吸动效，越到最后越有紧迫感，平时保持绝对安静。
  • 大号数字，字体字号可调。数字字号 24–72 px 无极调节，字体可自定义并配置后备字体（默认 Consolas），标题与日期字号专门配比，教室后排、工位对面都能一眼看清。
  • 开机自启 + 托盘常驻 + 单实例保护。开机自动启动（可静默启动，只显示小窗不弹设置窗口）；关闭主窗口即最小化到托盘，托盘菜单可启停、可退出；内置单实例锁，重复启动会提示，避免多进程并发写坏配置。
  • 绿色单文件数据，一键导入导出。目标、位置、外观、文案全部保存在同级 config.json，复制整个目录即可迁移到新电脑，控制台内可一键导出 / 导入配置。

三、产品优点

相比“能显示倒计时”这个最低要求，CountdownSideBar 的优势更多体现在安装、稳定与定制这些长期体验上。

  1. 零安装、零依赖。使用系统自带的 .NET Framework 4.8，不需要安装运行库、不需要管理员权限，解压双击即可使用。
  2. 极致轻量。主程序单个 exe 约 451 KB，常驻内存开销极小，老旧电脑也能流畅运行。
  3. 数据完全私有。不联网、不上传云端，也几乎不写注册表（仅在开启开机自启时写入一条当前用户启动项），适合对隐私敏感的用户。
  4. 稳定性有兜底。配置采用“临时文件 + 原子替换”方式写入并保留备份；配置损坏时自动备份为带时间戳的副本并弹窗告知，而不是悄悄重置；未捕获异常会写入日志文件，便于定位问题。
  5. 界面足够体面。令牌化配色体系 + 玻璃质感小窗 + 克制的 180 毫秒过渡动效，摆在桌面不廉价，也适合截图做演示、直播出镜。
  6. 省心细节。拖动位置自动记忆、边缘自动吸附、退出时自动保存；改乱了还能“重置外观”一键回到默认。
  7. 可定制、可二次开发。单文件源码、结构清晰，附带一键编译脚本，改颜色、改字号、改逻辑都能自己上手。
  8. 多显示器与高 DPI 友好。支持负坐标（副屏在主屏左侧或上方）、虚拟屏幕边界钳制，拖动按 DPI 精确换算，高分屏不漂移、不抖动。

四、典型应用场景

  1. 考试倒计时：高考、中考、考研、四六级、公务员考试，学生贴在桌面角落，每天抬头就看到还剩几天。
  2. 教室与培训机构大屏：配合大字号与深色主题，投影到后排也能看清；全屏播放课件时自动避让，不遮内容。
  3. 项目里程碑：产品上线、大促开始、交付截止，项目组工位常驻一个小窗，进度条一眼看出时间过去了多少。
  4. 纪念日与婚礼：把“距离我们的婚礼还有”放在桌面，配合背景图片与自定义配色做成专属样式。
  5. 假期、年假与发薪日倒数：纯按天倒数的轻量场景，设置一次就不用再管。
  6. 坚持打卡（正计时）：戒烟第几天、连续健身第几天、背单词第几天，用“已坚持”做正向激励。
  7. 主播与直播场景：开播倒计时、抽奖倒数，配合点击穿透或全屏避让，完全不影响直播操作。
  8. 会议与培训限时：演讲限时、茶歇倒计时，迷你条形态放在屏幕角落，不干扰投屏内容。
